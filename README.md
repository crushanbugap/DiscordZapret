## ⚙️Установка и использование

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите провайдера, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query` (провайдер Cloudflare может быть заблокирован)
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках ОС — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это рекомендуемый вариант
    * На роутерах Keenetic активируйте параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/crushanbugap/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Откройте подходящий файл
    * Чтобы найти работающую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск: **`service.bat`** -> `Install Service` -> *выберите нужную стратегию*

## ℹ️Что делают основные файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегий

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте варианты (ALT, FAKE и другие), пока не найдёте подходящий для себя**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб
  - **`Check Status`** — просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — изменение режима обхода для игр и других сервисов, работающих по UDP и TCP на портах выше 1023.  
  **После смены значения стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние (включено/выключено).
  - **`IPSet Filter`** — настройка обхода для сервисов из `ipset-all.txt`.  
  Опция полезна при проверке ресурса, который без zapret работает, а с ним — нет  
  В скобках указано текущее состояние:
    - `none` — IP-адреса не проходят проверку
    - `loaded` — IP проверяются на наличие в списке
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** — замена используемого фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ручная проверка обновлений
  - **`Run Diagnostics`** — поиск распространённых причин неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапной остановки работы
  - **`Run Tests`** — проверка стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров (Cloudflare, Amazon и других)


## ☑️Частые вопросы и неисправности

### После запуска `general*` нет видимого результата

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/crushanbugap/zapret-discord-youtube/issues/522)

### Не удаётся подобрать стратегию
- Откройте командную строку с правами администратора
- Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не подключается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если hosts окажется устаревшим, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - Откройте файл `hosts` в новой папке текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` (либо замените ранее добавленный аналогичный блок)
  - Сохраните файл и снова проверьте соединение. Если результата нет, убедитесь, что hosts действительно был сохранён.

#### Работа не гарантируется. При отсутствии результата используйте [версию Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/crushanbugap/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Стратегия может помогать некоторое время, а затем перестать работать после того, как её обнаружат.
> В репозитории собрано много вариантов обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них и измените параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте `service.bat` -> `Run Diagnostics` и исправьте найденные ошибки

- Убедитесь, что нужный адрес присутствует в списках доменов или IP

- Переберите другие стратегии (**`ALT`**, **`FAKE`** и прочие)

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/crushanbugap/zapret-discord-youtube/issues/765)

### Полная переустановка или обновление
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Выполните `service.bat` -> `Run Diagnostics` и устраните ошибки; в конце подтвердите `Y`
- Удалите каталог zapret
- Загрузите свежую версию [со страницы релизов](https://github.com/crushanbugap/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива через ПКМ. Если внизу справа есть "Разблокировать", включите параметр, нажмите "Применить" и "ОК"
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов
- Запускайте разные скрипты `general` и проверяйте ресурсы. Если соединения нет, закройте программу через значок замка на панели задач и попробуйте другую стратегию
- После выбора рабочей стратегии включите автозапуск: `service.bat` -> `Install Service` -> выберите её

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Узнайте имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Испытайте остальные стратегии, особенно если прежняя раньше работала.
- См. также [#251](https://github.com/crushanbugap/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается сайт YouTube, и запустить её.
- В `service.bat` перейдите в `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord после очистки кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ею.
- Если браузерная версия тоже не работает, снова проверьте все стратегии. YouTube и Discord могут работать на разных стратегиях.
- См. также [#252](https://github.com/crushanbugap/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/crushanbugap/tg-ws-proxy)
- Либо используйте бесплатные MTProto-прокси из интернета

### Игры не работают

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Обычно помогает следующий порядок:
- через `service.bat` обновите ipset и включите `Game Filter`
- если это не сработало, дополнительно включите `ipset any`

Учитывайте, что `ipset any` может нарушить доступ к большому числу сайтов. Не оставляйте этот режим включённым постоянно: определите IP-адреса игры и добавьте их в `ipset-all.txt`

Если результата всё равно нет, создайте обсуждение в разделе [Discussions](https://github.com/crushanbugap/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Здесь нет решения моей проблемы

- Опишите проблему [здесь](https://github.com/crushanbugap/zapret-discord-youtube/issues)

## 🗒️Как добавить адреса других ресурсов

Дополнительные адреса для обхода указываются в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — исключаемые домены, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
